# summary.ave5proj

Summarize information on projection method used.

## Usage

``` r
# S3 method for class 'ave5proj'
summary(object, printcall = FALSE, ...)
```

## Arguments

- object:

  An object based on the
  [`ave5proj()`](https://mattwarkentin.github.io/canproj/reference/ave5proj.md)
  function.

- printcall:

  Whether to print function `Call` for ave5proj.object (`T` or `F`).

- ...:

  Other parameters

## Value

An information table describing the method used.
