# glm.acproj

Summarize estimations from the final model.

## Usage

``` r
glm.acproj(acproj.object)
```

## Arguments

- acproj.object:

  An object based on the
  [`acproj()`](https://mattwarkentin.github.io/canproj/reference/acproj.md)
  function.

## Value

A summary table from the `glm.object`.
