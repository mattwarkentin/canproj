# glm.adpcproj

Summarize estimations from the final model.

## Usage

``` r
glm.adpcproj(adpcproj.object)
```

## Arguments

- adpcproj.object:

  An object based on the
  [`adpcproj()`](https://mattwarkentin.github.io/canproj/reference/adpcproj.md)
  function.

## Value

A summary table from the `glm.object`.
