# summary.acproj

Summarize information on projection method used.

## Usage

``` r
# S3 method for class 'acproj'
summary(object, printpred = F, printcall = F, digits = 0, ...)
```

## Arguments

- object:

  An object based on the 'acproj()' function.

- printpred:

  Whether to print the observed and predicted number of cases (`T` or
  `F`).

- printcall:

  Whether to print function `Call` for acproj.object (`T` or `F`).

- digits:

  Number of digits in output, default (`0`) is integer only.

- ...:

  Other parameters.

## Value

An information table describing the method used.
